# What We're Reading — a Home Screens plugin

Book covers of what each person is reading, from a Todoist project ("Title by Author", labelled with the reader). Covers from Open Library.

Install: Home Screens editor → Plugins → Install from URL…

```
https://github.com/tweetyboopdev2022-code/home-screens-reading-now/releases/latest/download/reading-now.tgz
```

Build: `npm install && npm run build`
